Checklist de instalação

Central de Chamados TI — do zero até rodando no tablet. Marque cada passo conforme for concluindo (as marcações não são salvas ao fechar a página, é só um guia de acompanhamento).

0/12
PASSO 1
Instalar o XAMPP

Baixe o instalador em apachefriends.org e rode com as opções padrão. Na tela de componentes, deixe marcados Apache, MySQL e PHP (o phpMyAdmin vem junto automaticamente).

PASSO 2
Copiar o projeto para o htdocs

Extraia o zip chamados-ti e copie a pasta inteira para dentro do XAMPP. O caminho final precisa ficar exatamente assim:

C:\xampp\htdocs\chamados-ti\index.php
PASSO 3
Ligar Apache e MySQL

Abra o XAMPP Control Panel e clique em Start nas linhas Apache e MySQL. As duas devem ficar verdes.

Apache não sobe? Geralmente é a porta 80 ocupada (Skype ou IIS)
PASSO 4
Importar o schema.sql

Acesse o endereço abaixo, clique em Importar no menu superior, escolha o arquivo database/schema.sql dentro da pasta do projeto, e clique em Executar.

http://localhost/phpmyadmin
PASSO 5
Gerar o hash da sua senha

No navegador, acesse o endereço abaixo trocando SUASENHA pela senha que você quer usar. Copie o texto gerado (começa com $2y$10$).

http://localhost/chamados-ti/gerar_senha.php?senha=SUASENHA
PASSO 6
Colar o hash no seu usuário

No phpMyAdmin: chamados_ti → agentes_suporte → Procurar → clique no lápis (Editar) na linha felipe.leite → cole o hash no campo senha_hash, substituindo o texto atual → Executar.

PASSO 7
Testar o seu login

Acesse o endereço abaixo e entre com usuário felipe.leite e a senha escolhida no passo 5. Se cair no dashboard zerado, está tudo certo.

http://localhost/chamados-ti/login.php
PASSO 8
Cadastrar os outros 2 agentes

Já logado, vá na aba Equipe e cadastre os dois pelo formulário (nome completo, usuário no formato primeiro.ultimo, senha inicial). Combine a senha com cada pessoa antes de salvar.

PASSO 9
Apagar o gerar_senha.php

Delete (ou mova para fora da pasta) o arquivo abaixo. Ele não deve ficar acessível depois de cumprir a função de gerar seu hash inicial.

C:\xampp\htdocs\chamados-ti\gerar_senha.php
PASSO 10
Descobrir o IP da VM na rede

No Prompt de Comando da VM, rode o comando abaixo e anote o IPv4 (ex: 192.168.1.50). É esse endereço que o tablet vai usar, no lugar de localhost.

ipconfig
PASSO 11
Testar no navegador do tablet

No tablet, acesse o endereço abaixo substituindo pelo IP do passo 10. Preencha um chamado de teste e confirme que ele aparece na aba Chamados quando você acessar pelo computador.

http://IP-DA-VM/chamados-ti/ Não conecta? Confira o Firewall do Windows liberando a porta 80 para conexões de entrada
PASSO 12
Configurar o modo quiosque no tablet

Instale o app Fully Kiosk Browser (gratuito) no Tab A7 Lite, configure a URL inicial como o endereço do passo 11, e ative o modo quiosque para travar a navegação só nessa página.

Problemas comuns

MySQL não inicia no XAMPP

Geralmente é outro serviço MySQL já rodando na porta 3306 (ex: instalação antiga). Feche outros serviços de banco de dados na VM ou troque a porta do MySQL na aba Config do XAMPP.

Página em branco ao abrir o sistema

Normalmente é erro de conexão com o banco. Confira se o MySQL está ligado e se os dados em config.php (host, usuário, senha) batem com o que está configurado no XAMPP.

Tablet não abre o endereço da VM

Confirme que tablet e VM estão na mesma rede Wi-Fi/cabeada, e libere a porta 80 de entrada no Firewall do Windows (Painel de Controle → Firewall do Windows Defender → Configurações Avançadas → Regra de Entrada).

Erro "Usuário ou senha inválidos" mesmo com a senha certa

Confira se o hash foi colado por inteiro no phpMyAdmin (sem cortar o começo ou o fim) e se não sobrou nenhum espaço antes ou depois do texto colado.
